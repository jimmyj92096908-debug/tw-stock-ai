## 新程式安全設計

保留 src/trained_factor_model.py 原有 LATEST_MODEL_SQL 供其他研究用途；另新增專用 FROZEN_SAME_DAY_MODEL_SQL，使用 psycopg 的單一 typed %s::date 參數，固定同日分數與原始交易收盤價的合格股票 JOIN。

在同一 REPEATABLE READ 快照，先分別取得最新正價交易日和最新有效評分日；如果日期不一致或任何一個不存在，直接以原本錯誤訊息拒絕，不掃描完整股票來源、不做任何封存寫入。日期完全相符才使用新查詢。此查詢仍使用 14 日內有效的最新官方上市資料、stock_master、模型排除股票清單，並明確排除 1808 和 1589。第二層 Python 完整研究名單驗證也拒絕 1589。

原始模型係數、歷史即時性、不可回溯封存、全 cohort、不可使用未來標籤、研究資料不得成為下單信號等防護維持不變。PR #264 的 650MB 及未知 Neon 傳輸額度 gate 仍先於昂貴封存查詢。**本次未取得真實最新封存成功證據，不將 CI PASS 當成 OWNER 真實業務 PASS。**

## 尚未執行的容量工作

現在不對 753MB 正式庫刪除資料、重建索引、開付費服務或提高上限。後續可先唯讀觀察 pg_stat_user_indexes 及大表死 tuple 指標，再設計可逆的容量方案；但索引使用計數為零不能單憑此判定可刪。五年歷史優先用本機已加密 AES 及免費離線存證驗收，而不是往將滿的正式 Neon 大量回填。所有正式資料 DML、DDL 仍須另行明確授權。
