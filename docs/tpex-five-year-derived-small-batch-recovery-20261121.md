# 上櫃五年官方行情之後：小批衍生因子重算器（僅手動）

因官方來源長批次會逐日新增數百個交易所驗證 K 線，歷史全日因子必然暫時過期。新 `scripts/tpex_five_year_derived_recompute.py` 提供**每次最多 3 檔、最多 5,000 個原始交易日**的人工可控衍生因子重算。它沿用 `tpex_stale_factor_refresh.choose` 對歷史來源及最新分數過期檢查，但不錯誤要求目前已完整的 879／879 最新評分；對每檔依序先重建調整價、技術、SMC，再重新計算其最新綜合研究分數。

執行前驗證官方來源至少 100 日、合格研究池至少 700 檔、沒有原有月份調整量額錯誤、800MB 安全停止線距離至少 40MB，並為每個原始交易日額外預留 3KB 的保守可能 UPSERT 空間。每檔獨立證明原始 OHLCV 筆數、量額總和及最新來源下載時間**完全未改**，重算後驗證所有日期衍生列及最新分數的時間新鮮度。若任何資料遺失、重新計算不到所需筆數、評分仍過期或容量不足，立即停止並保留證據，不擅自修改原始 K 線。

**排程與續跑**：僅在使用者人工從 GitHub Actions `workflow_dispatch` 執行，預設 `apply=false` 只做來源與容量預檢，絕無自動寫入。執行 `apply=true` 時必須同時持有既有 `twstock-indicator-catchup` 和 `twstock-tpex-dated-official-history` 互斥鎖，因此活躍的五年行情原始回補不會與歷史因子並行。重算單一檔失敗時，來源 K 線不受影響；正式重新啟動將重新挑選仍缺失／過期的股票。

此流程尚未在原始行情正在回補期間執行正式因子寫入。不假設 800MB 能裝下每檔的所有五年因子，亦不會把歷史來源擴充等同模型具備正超額報酬。
