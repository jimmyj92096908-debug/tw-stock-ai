# 五年原始行情 → 按需 AI 特徵與原始價回測介接（研究限定）

## 已有舊模型與新資料的差異

既有 `tw-factor-ridge-1` 使用 `daily_composite_scores` 中 0–100 分的整合因子。五年來源回補正在把更早的官方 OHLCV 寫入 `daily_prices`，當歷史調整價、技術與 SMC 的每日表尚未完成時，不能把原始 OHLCV 給舊模型當成「已經重算所有歷史分數」。新 `src/raw_factor_feature_bridge.py` 實作**不同 schema**的 12 個 raw-price 因子：5/20 日原始價格報酬、MA20/55 比值、RSI14、ATR14 比率、來源單位正規化之成交量相對20日均量、SMC 趨勢與 BOS／CHOCH。

程式只在一檔股票實際存在、至少 240 個真實交易日的歷史價格上使用既有 `compute_indicators`／`compute_smc` 及 `normalize_source_units`。單一交易日若資料不足就**整日不計算**，不虛構價格或填補缺漏交易日；最新研究可直接取用原始交易所行情，在記憶體中計算，不會新增 `daily_adjusted_prices`、`daily_technicals`、`daily_smc` 的永久資料列。

**重要差異**：原始日 K 含除權息價格跳空，這批 raw-price 特徵並非經歷史公告調整的總報酬。它們僅有「公式上使用訊號當天及以前的原始價格」的因果性，沒有歷史資料實際抓取／公告時點的獨立證據。不得把這批不同特徵假扮為現有 Ridge 分數／已通過投資績效驗證。

## 離線整批標籤與原型模型的時間隔離

`src/raw_factor_walkforward.py` 對**明確固定的整個研究股票名單**依每個原始 `signal_day` 逐檔擷取**只到該日的來源前綴**計算特徵，然後另讀*下一實際交易日進場*到*第六個真實交易日出場*的原始價標籤。如有任何股票價格／標籤缺失或停牌使進／出日期無法整批對齊，就將**整個訊號日股票池**排除，而不是只排除被停牌或下跌的股票。僅使用出場日在測試開始日前已成熟的發展期標籤擬合實驗 Ridge；將平均／標準差統計只從訓練資料估計，不由保留測試期反向影響訓練。測試交易窗不重疊，使用示意交易成本 14.25 bps 每邊佣金＋30 bps 賣出交易稅，以及 10/30/60 bps 每邊滑價壓力情境，所有成本都明列不是實際成交報價。

正式唯讀實驗 `scripts/tpex_raw_model_readonly_experiment.py` 使用固定 6 檔目前主檔上櫃股票 1742、1777、1781、1784、1785、1788，並最多取 50 個真實既存交易日作測試。這些股票是**今天已有充足歷史行情的方便研究樣本**，不是 2022 年當時可買的完整掛牌名單；將它們視為過去每個時點的真實市場就是存活者偏差。不論實驗評分是正是負，**不准發表超額報酬或替換正式 Ridge 模型**，因為原始價不含真實除息調整、沒有完整歷史公告版本及未觸碰的未來前瞻樣本。

## GitHub 自動執行與付款限制

`.github/workflows/tpex-raw-asof-ai-research.yml` 只在獨立首次新增標記觸發一次正式真實資料*READ ONLY*研究證據，也可由工作完成後自動再做，或由人手動再執行唯讀測試。全部都設 `default_transaction_read_only=on` 加 `REPEATABLE READ READ ONLY`，不修改 Neon 原始股價、因子評分、LINE Webhook 或投資交易。原有五年歷史來源寫入可以繼續進行而不受干擾，不新增付費 API 或固定每日 Actions 排程。

## 此階段無法立即消除的障礙

- 歷史非當前 `stock_master` 的上櫃下市、上市與停牌主檔及真正各日期可投資股票池尚未完成驗收。
- 官方財報 `first_observed_at` 仍不可回填成歷史財報公布日；未得到原始公告時間證據就不以財報訓練過去的標籤。
- 正式 Ridge v1 淨超額表現及新未見樣本的獨立驗證仍未達標，模型發佈／LINE 交易訊號／自動下單全部維持禁止。
