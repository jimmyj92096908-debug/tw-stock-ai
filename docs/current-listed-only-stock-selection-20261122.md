# 選股需求：不要下市股票（2026-11-22）

自這次修改起，**新的** TWSE/TPEx 選股研究、Ridge 研究排名、歷史訓練與調整價回測選樣，以及每日報告前十名，必須同時存在於：

1. Neon `stock_master`（公司代號／市場一致），以及
2. 最近 **14 日內**從官方 TWSE／TPEx 公司基本資料取得、以不可覆寫方式保存的最新公司名單（優先使用同週 SHA-256 連結的訂正紀錄）。

若沒有最新可信官方資料，SQL 選股池會回傳**空集合，絕不退回只有 `stock_master` 的舊清單**。不增加任何付費資料服務、不觸發 LINE 發送、不啟用下單。為使同時上市／上櫃市場移轉的股票只保留實際現存市場，採用 `(market,stock_id)` 主鍵交集。

本次正式唯讀核對：目前 `stock_master` 有 1,991 筆，最新官方發行人名單 1,990 筆，完全交集 1,990 筆，有 1 筆只在舊主檔：**1589 永冠-KY**。官方現行名單未列示並不自動證明法律上的下市原因，但根據你的要求，無法證明仍在現行官方名單的股票**一律不參與新的研究推薦**。

**保留歷史資料：** 不刪 `daily_prices`、`daily_adjusted_prices`、`daily_composite_scores`、此前不可覆寫的 `research_forward_frozen_cohorts`，不回頭修改發生於 2026/11/20 的封存預測。即使已下市股票曾有歷史股價也只保留為原始研究／稽核證據，今後不再進入官方最新名單篩選後的研究評分。

**回測限制：** 你要求「只看現在還上市／上櫃的股票」，這會產生**存活者偏差**：過去下市公司的虧損或風險未被包含，不能把這種回測說成完整歷史市場真實績效。獨立未見的未來觀測、完整公司行動公告時點、股利總報酬、正式模型發布條件仍需另外驗證。

`scripts/current_listed_only_audit.py` 只執行 Neon `READ ONLY REPEATABLE READ`，統計官方現行名單與主檔交集、排除個股、來源觀測時點及存活者偏差旗標。GitHub 的一次性證據報告不修改任何資料庫資料、LINE Webhook 或模型權重。
