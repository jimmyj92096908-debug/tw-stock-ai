# 五年官方行情回補期間可同步完成的免費三項工程

1. **容量預估與拒絕超限**：新 `scripts/tpex_five_year_capacity_plan.py` 透過真實 `pg_total_relation_size`（含索引）與 `COUNT(*)` 估測價格、調整價、技術與 SMC 單列物理空間。為不預估得過度樂觀，對每個新增資料列採 1.5 倍實測單列空間，對每檔完整衍生系列重算預留 2 倍 UPSERT 堆積空間；不可把估算當成資料庫保證。安全線 800MB，另保留至少 40MB 因子批次餘裕。

2. **有限衍生重算預備**：以正式 Neo​​n 唯讀 SQL `LEFT JOIN` 真正核對價格日期是否有調整後價格、技術與 SMC。只列出最多 5 檔、合計最多 5,000 個原始行情日的候選；沒有寫入因子或綜合評分。原始行情批次仍在執行時，**禁止**平行重算；即使容量看似足夠，JSON `manual_derived_recompute_permitted_now=false`。要等 GitHub 五年行情正式批次停止，且重新預檢成功後才能開始下一階段的受控衍生因子重算。

3. **故障續跑與最終驗收**：現有五年價格回補逐日 `INSERT ... ON CONFLICT DO NOTHING`，即使超時，已驗證日 K 仍保存。主分支新增 `workflow_dispatch` 人工續跑：預設 apply=false，沒有任何 DB 寫入；只有明確 apply=true 且 runner 重新跑全部官方來源測試與容量檢查，才以同一 `twstock-tpex-dated-official-history` 鎖繼續缺漏日。已有的獨立唯讀來源驗收在人工續跑結束後也運行，記錄剩餘來源日期和歷史因子過期情況。不允許對任意失敗自動無限重試、也不允許取消現有運行中的 job 重複排隊。

完整 879/879 只描述當時既有行情的完整歷史因子；當五年來源新價持續插入時，必須重新做歷史衍生因子，因而短期不維持 879/879。模型前瞻回測仍受資料公告 as-of 來源、交易成本、檔案封存與獨立未來觀察期約束，沒有被這個工程流程豁免。
