# 官方歷史股票母體與全市場除權息：在免費額度下可執行的實際資料管線

這是原專案第五年行情回補期間新增的**資料來源證據及小型不可覆寫觀測**，不是宣稱已擁有全部 2021–2026 年上市／下市名單或完整歷史現金股利。

## 官方股票公司基本資料（上市、上櫃）

使用專案已核實的官方 TWSE `opendata/t187ap03_L`、TPEx `mopsfin_t187ap03_O`，不是第三方付費 API。當前兩個網站的公司基本資料分別含「上市日期」、「上櫃日期」欄，轉換民國／西元日期前強制檢查日期合法、原始公司代碼、同一市場重複、觀測時點。每次只讀 2 個官方 GET，雙市場單次限制 3000 檔／市場，輸出 `current_api_listing_date` 和完整原始資料來源 URL 的 SHA-256，與 Neon 當前 `stock_master` 獨立比對。

重要：即使現時政府公司主檔顯示某家公司 2020 年上櫃，也不證明那家公司 2022 年每個日期都可以交易，不顯示此前已下市、移轉市場、停復牌的公司。它只能補充**今天仍登記公司的官方掛牌日期證據**。現有 `updated_at` 也不是實際 IPO 日，無法直接消除存活者偏差。將來必須另外得到獨立官方歷史下市／停牌／復牌及公告首次可得性，才能將 `full_historic_point_in_time_investible_universe_approved` 從 `false` 解除。

新增小型 `official_issuer_weekly_snapshots` 表：每週只插入至多 **一份**目前官方全公司名單 JSON，整份小於 1 MB，資料庫伺服器記錄真正首次 `observed_at`。主鍵 `observed_week`，`ON CONFLICT DO NOTHING`，不同來源 SHA-256 衝突則報錯、絕不覆寫。Postgres `BEFORE UPDATE/DELETE` 觸發器直接封鎖修改，明確驗證資料庫 650MB 安全停止線。這些是**從今日開始累積的真實每週歷史觀測**，不能用當前資料事後模擬五年前資料。

## 全市場除權息與減資：候選資料，非總報酬已完成

沿用現有官方四個資料源 TWSE `TWT49U`、`TWTAUU`，TPEx `exDailyQ`、`revivt`。現有 `corporate_actions_data.py` 只正式寫入 4 個手工驗證個股，不改它的受控正式寫入範圍。新 `scripts/official_dividend_monthly_preview.py` 在每次觸發時只讀**最近 21 個實際曆日**，最多 **4 個有界交易所官方來源 GET**（TPEx 新版 exDailyQ 暫時錯誤時只嘗試一次官方舊版後備）；從整份交易所資料提取符合 4 位數代碼的公司行動、實際除權息日、原始參考價及前收盤價比例、真正明列的每股現金股利（若官方欄位有值）、真正明列的減資換股股數，以及當時真正**第一次取得資料**的時間。

股票已不在今天主檔則標記待審，不靜默消除可能下市公司；現金股利缺漏或不是純除息時標記未驗證，不能從價差硬算出「公司當時發多少現金」。相同公司、日期、類別及相同經濟數據的重複交易所來源列只在研究資料報告中合併，不更動原資料庫。**交易所除權息參考價、實際現金股利、原始發行公司公告日期是三種不同證據**，不得互相冒充。這個月度研究報告不是五年完整除息，也不會修改 `daily_prices`、`daily_adjusted_prices` 或已封存模型。

## 自動化、免費與安全

`.github/workflows/official-free-issuer-dividend-evidence.yml` 在一次性 GitHub main marker 成功合併時真正執行一次，往後只利用現有 `Taiwan Stock AI - Daily Data` 成功的排程事件，沒有新增高頻 cron。平日執行有限的官方只讀比對與月度候選證據；**每週五**額外經過容量／網路使用（若可得）核對後，最多寫入一份當週不可覆寫的公司名單快照。手動預設仍是唯讀，只有 `apply_weekly_issuer=true` 會允許這份小型資料快照；其他全部資料表都不會被修改。若來源格式、官方 SSL 或容量限制異常則停止並保留 Artifact，不能當成空資料／成功報酬驗證。

每次 GitHub Artifacts 保留 14 日；正式歷史公司名單的可靠累積在 Neon 的 append-only 週快照，不依賴 Artifacts 長期存在。
