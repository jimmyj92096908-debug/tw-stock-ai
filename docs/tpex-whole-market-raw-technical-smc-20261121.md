## 只讀全市場執行

`scripts/tpex_whole_market_raw_factor_audit.py` 以 Neon `default_transaction_read_only=on` 與同一 `REPEATABLE READ READ ONLY` 快照：
1. 真實查詢目前全部 898 檔 `stock_master` 的原始有效日期數、未知來源單位、最新交易日期及目前已永久儲存的調整、技術、SMC 行數，並驗證所有計數與來源身份。
2. 針對所有 >=240 日且來源單位已核實的股票，以 20 檔一頁，一檔只下載最新 **320 個真正存在的交易日 K**；三個衍生指標都使用既有 `src/raw_factor_feature_bridge.py` 提供的現有 `normalize_source_units`、`compute_indicators`、`compute_smc`，直接在 Python 記憶體重建 12 項 **RAW，不是除權息調整** 的 RSI/MA/ATR/成交量及 SMC 結構訊號。
3. 每隔 42 檔定期抽樣對同一個歷史交易日比較含／不含下一交易日資料的特徵向量：如果下一日改變過去的指標，立即拒絕；也不會將未滿 240 天、未在最後市場日交易或來源身份無法確認的股票偷偷計入最新訊號。
4. 每一檔可重現的輸入價格 SHA-256、特徵版本、當天 12 個因子、是否完成未來日隔離測試都寫入 GitHub Artifact 的完整研究證據 JSON，永久每日衍生資料表**零新增**，不新增成千上萬個歷史衍生列。
5. 任一股票無法在嚴格 240 日條件下重建時，驗證報告保留明確的失敗股代碼和失敗型別，GitHub 任務標記失敗，不能聲稱已全市場完成。

每一檔取得 320 日 K，主要是算最新已知市場日的原始技術因子；這**不是**用 320 日窗口宣稱已對全部五年每個股票歷史日獨立重算或完成全歷史回測。必要的完整歷史多窗口因子研究仍應依真實用途按需取來源歷史，且不能把原始價回測當成已完成現金股息總報酬。
