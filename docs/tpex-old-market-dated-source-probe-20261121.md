# 上櫃 2025／2022 年舊交易日全市場來源驗證（僅唯讀）

在正式 Neon 已完成 5520/6762 共 140 筆舊月份官方行情回補、兩檔完整歷史因子恢復、879/879 驗收通過後，若仍以逐檔×60個月爬取 ~861 檔股票，交易所 HTTP 請求量很大，可能超出免費 Actions、網站限流或資料庫計算負擔。

現有 `src/tpex_dated_history.py` 已有 **逐日全市場、只新增缺漏主鍵、獨立 >=10 筆同日收盤 98% 一致的安全閘門**，但原計畫只看近 366 天，未證實 2025／2022 舊日期是否仍可指定日期查詢。正式 Neon 唯讀證實 2025-12-31 與 2022-12-30 分別有 18／16 檔獨立保存的有效收盤，因此這兩個交易日可作為真實測試錨點，而非猜測新上市日。

`scripts/tpex_old_dated_market_source_probe.py` 僅以既有官方來源端點 **2 個 HTTP GET**，查詢這兩日的全市場 K 線，篩選 `stock_master` 上櫃股票，對照真實既存同日收盤，要求至少 10 筆、98% 完全相符。正式 Neon 全交易 `READ ONLY`，不寫原始股價、技術、SMC、財報、LINE、交易，不新增排程；正式 GitHub 只在首次新增精確標記時執行一次（也可手動唯讀再驗）。

若舊日期來源失敗，回報拒絕，**不偷換當年最新日期**，回退至已驗證的逐檔逐月安全方案；若都驗證通過，僅表示市場級舊日期來源具備**兩日可行性**，還不等於五年完整價量或可直接大量回補。任何後續擴大寫入必須另驗市場日期錨點、成本／儲存增量、原價不覆寫與衍生因子後續重算。
