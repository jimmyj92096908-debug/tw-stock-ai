## 原始問題及已完成程式修正

2026-11-20 有 **1,973** 檔股票有有效收盤價；同日技術／SMC 只有 **12** 檔，綜合評分只有 **7** 檔。原本的補算 SQL 只比較技術／SMC 的**歷史筆數**，忽略最後有效收盤日期。例如 `tpex/8937` 的指標行數多於有效價行數，但缺 11/20 有效收盤日的指標，因而被錯誤排除。

[PR #55](https://github.com/jimmyj92096908-debug/tw-stock-ai/pull/55) 修正候選選取、存入後驗證與唯讀覆蓋率探測；加入 **2330、6213、4919、7827、8937** 優先順序、60 日真實歷史與每市場 20 檔上限、每股 SAVEPOINT；所有修正先通過 Python 與隔離 PostgreSQL CI。
